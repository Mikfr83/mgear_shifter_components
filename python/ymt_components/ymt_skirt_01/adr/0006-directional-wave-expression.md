# ADR-0006: 方向付き周期波と房ごとの位相差

Status: Proposed
Date: 2026-09-05
Owner: ymtshiftercomponents maintainers
Supersedes: ADR-0004 の周期波の合成式と新規リグのホスト属性既定値
Superseded by: none

Implementation: 2026-09-05。
各 Maya 版の実行結果、互換性比較、リグ構築、画像、未検証範囲は [検収記録](../../../../../../../colliders/2.1.0/colliders/docs/validation/wave-expression.md) を参照する。

## 背景

ADR-0004 の現在値だけを使う変形方式は維持する。
ユーザーはレビューで挙げた幾何座標、CV 解像度、シアー、リタイムの制約を受け入れ、表現面の改善を実装するよう指定した。
この変更は方向付きの縦揺れ、縦波と周方向の波の独立した振幅、房ごとの位相差、send の独立した強度操作を扱う。

従来の縦波は同じ高さの全周に同じ半径変位を与えるため、円形断面では膨張と収縮になる。
前後に振れるシルエットには、向かい合う側へ逆符号の変位を与える成分が必要である。
周方向のひだを回す成分は別に残し、縦揺れの方向を回したときに周方向の位相を変えない。

## 継続する契約と制約

入力は現在の属性値、行列、ジオメトリだけとする。
シーン時刻の参照、過去フレームの評価、内部の運動状態、参照座標の保存は追加しない。
変形順は `ringSkin -> skirtWaveDeformer -> skirtCollideDeformer` のままとする。
ガイドの `wave` が False の場合は wave 用ノードと属性を作らない。

波形は現在の入力点から求める `v` と `theta` で評価する。
最大高さによる正規化があるため、一部分の高さ変更が他の部分の位相と振幅を変え、ねじりは房ごとの位相差の配置も変える。
今回は固定高さ、参照 U/V、解像度に応じた幅制限を導入しない。

デフォルトの V 方向4スパンは7列の CV を持つ。
幅の狭い send が CV 列の間に入ると、カーネル内に点がなく変位がゼロになることがある。
幅を広げるか `rebuildSpansV` を増やして調整する。
周波数と波形の鋭さも CV の解像度に制限される。

ベル軸に直交するワールド空間の変位を継続する。
ベルローカルの高さが保存されるのは、ベル行列の高さ方向と半径方向が直交する場合である。
シアーを含む場合のローカル高さ保存は保証しない。

リタイム後に同じ形状を得る条件は、形状に寄与する全入力へ同じ時間写像を適用することである。
ホスト以外の属性、ramp の子属性、上流の行列やジオメトリを別にアニメーションしている場合は、それらも対象に含める。
`scaleKey(node)` だけでは非 keyable の ramp 子属性のキーが取り残される場合がある。
Cached Playback の保証には実際のキャッシュ生成と復元を含む検証が必要である。

半径方向だけの変位は振り子のシルエットを近似するが、円弧軌道、布の長さ、面積、体積の保存は保証しない。
後段の衝突補正で内向きの変位が弱くなることがある。
衝突補正は CV 単位であり、補間された面の非貫通を無条件には保証しない。

## 追加属性

既存のノード属性は名前、型、既定値を維持する。
新しい属性のノード既定値は、既存シーンをロードしたときの出力を維持する値とする。
新規に構築するリグのホスト既定値は、方向付きの揺れを使い始められる値とする。
旧実装との分岐やバージョン判定は追加せず、下記の一つの式で評価する。

| ノード属性 | 型と範囲 | ノード既定値 | ホスト属性 | ホスト範囲と既定値 |
| --- | --- | ---: | --- | --- |
| `idleAmplitudeV` | double、0以上、soft max 2 | 1 | `swayVertical` | 0..2、1 |
| `idleAmplitudeU` | double、0以上、soft max 2 | 1 | `swayAround` | 0..2、0 |
| `idleDirectionality` | double、0..1 | 0 | `swayDirectional` | 0..1、1 |
| `idleDirectionX` | double、無制限、soft -1..1 | -1 | `swayDirX` | 無制限、soft -1..1、-1 |
| `idleDirectionZ` | double、無制限、soft -1..1 | 0 | `swayDirZ` | 無制限、soft -1..1、0 |
| `idleDirectionSpace` | enum、World=0、Bell Local=1 | 0 | なし | リガー設定 |
| `phaseSpread` | double、0以上、soft max 0.5 | 0 | `swaySpread` | 0..0.5、0 |
| `impulseAmount` | double、0以上、soft max 2 | 1 | `sendAmount` | 0..2、0 |

`idleDirectionSpace` は非 keyable、channel box 表示とする。
他の追加属性は keyable とし、全追加属性から `outputGeom` への `attributeAffects` を登録する。
既存の `swayAmount -> idleAmplitude` は周期波全体の強度として残す。
`waveAmplitude -> amplitude` は全レイヤーの強度として残す。
`idleDirectionSpace` と既存の `impulseSpace` は独立した設定である。

## 方向付き縦波

`D = (idleDirectionX, 0, idleDirectionZ)`、`d = idleDirectionality` とする。
`|D| < 1e-5` の場合は方向ベクトルをゼロとする。
それ以外では、まず D を正規化する。
World の場合は、正規化した D から単位ベル軸方向の成分を除き、ワールド半径方向との内積を取る。
投影後に再正規化しないため、ベル軸に平行な方向は徐々に弱まり、軸と一致するとゼロになる。
Bell Local の場合は、正規化した D とローカル半径方向との内積を取る。
内積値を `q` とし、縦波の方向係数は `Q = (1 - d) + d * q` とする。

`d=0` は従来の膨張と収縮、`d=1` は逆側が逆符号になる揺れを作る。
方向ベクトルがゼロで `d=1` の場合、縦波はゼロになる。
方向の大きさは、閾値未満の場合を除いて周期波の強度に影響しない。
方向係数は U 波、send、加算ノイズには掛けない。

## 房ごとの位相差

既存の整数ハッシュによる value noise と、継ぎ目のない円周埋め込みを使う。
位相差のサンプルは次の式とし、V 方向の入力を含めない。

```text
N_phase(theta) = valueNoise(
    cos(theta) * noiseFrequencyU + 7.31,
    sin(theta) * noiseFrequencyU + 3.17,
    noisePhase)
delta = phaseSpread * N_phase(theta)
localPhaseV = wavePhaseV + delta
```

`delta` の単位は、主成分の位相と同じ cycles である。
同じ `theta` の縦列は同じ位相差を持つため、縦方向に送る形を保ったまま房ごとの進みと遅れを作れる。
`phaseSpread=0` の場合はノイズの評価を省略し、`localPhaseV=wavePhaseV` とする。
`noiseFrequencyU=0` の場合、位相差は全周で同じ値になる。

加算ノイズの `noiseAmplitude` がゼロでも位相差は機能する。
`noisePhase` と `noiseFrequencyU` は加算ノイズと共有する。
`noiseFrequencyV` は従来の加算ノイズだけに作用する。
`noisePhase` を固定すれば位相差の配置を固定でき、キーを付ければ配置を変化させられる。
共有操作が制作で支障になる場合に限り、位相差専用のノイズ操作を再検討する。

## 周期波の合成

`S`、黄金比 `g`、`c=idleComplexity` は ADR-0004 と同じ定義を使う。
`n=waveCountU`、`aV=idleAmplitudeV`、`aU=idleAmplitudeU` とする。

```text
phiV  = 2*pi * (localPhaseV - waveCountV*v)
phiV2 = 2*pi * (g*localPhaseV - waveCountV*v) + pi/2
phiU  = n * (theta - 2*pi*wavePhaseU)
phiU2 = n * (theta - 2*pi*g*wavePhaseU) + pi/2

T(a, b) = 0.5 * (aV*Q*S(a) + aU*S(b))  when n > 0
T(a, b) = aV*Q*S(a)                     when n = 0

W_idle = idleAmplitude * ((1-c)*T(phiV, phiU) + c*T(phiV2, phiU2))
```

V と U の振幅を変更しても、もう片方の寄与を自動で正規化しない。
`n>0` の係数 0.5 と、`n=0` で縦波を半減しない規則は継続する。
従って `swayAround=0` と `waveCountU=0` は同じ振幅設定ではない。
周方向の波だけを止める通常の操作には `swayAround=0` を使う。
新規リグで縦波の最大振幅を周期波の全体強度と揃えたい場合は `swayVertical=2` とする。

黄金比成分にも `localPhaseV` を使うため、房ごとのずれは同じ入力位相へのオフセットとして作用する。
V の位相差は U 位相を変えず、U の回転は V 位相を変えない。
`idleComplexity=0`、入力形状と行列が一定、方向とノイズ配置が一定の場合、V 位相の整数 cycles の進行でループできる。
複雑度が非ゼロのときは従来どおり整数 cycles の厳密なループを保証しない。
変化させた方向、振幅、ノイズ配置などもループ端で一致させる必要がある。

## send の強度

従来の方向付きカーネルの結果へ `impulseAmount` を掛ける。
`impulseAmount=0` の場合は send の計算を省略し、寄与を厳密にゼロとする。
これにより、方向と位置を保持したまま send の発生と消失をキーで操作できる。

`impulseX/Z` の大きさが既存の強度へ寄与する契約は継続する。
`sendAmount` はその独立した強度倍率であり、方向入力を正規化する変更ではない。
新規リグでは `sendDirX=-0.5`、`sendDirZ=0`、`sendAmount=0` とする。
従来と同じ強さで send を使う場合は `sendAmount=1` とする。
ノード単体の `impulseAmount` 既定値は1とし、保存済みシーンの send は維持する。

## リグの接続と導入

ホストへ上記7属性を追加し、対応するノード属性へ直接接続する。
方向の変換と位相差の評価はデフォーマー内で完結し、補助 DG ノードは増やさない。
新しい属性を登録していないプラグインをロードしている場合、wave を有効にした構築は不足属性と再ビルドの必要性を示して失敗させる。
旧プラグイン用の代替経路は用意しない。
Component と Guide の `VERSION` はともに `[2, 1, 0]` とする。

保存済みノードは追加属性の中立な既定値で従来の結果を維持する。
新規リグは `swayAmount=0`、`swayNoise=0`、`sendAmount=0` なので wave の寄与がゼロになる。
新しいホスト操作を既存リグに追加するにはリグを再構築する。
Maya 2022 から2027のプラグインをそれぞれビルドして検証する。

## 検討した選択肢

| 選択肢 | 判断 |
| --- | --- |
| 現行周期波のままノイズだけを強める | 変位の乱れは増えるが、方向付きの縦揺れと房の位相差を独立して操作できない |
| 全周を同じベクトルで平行移動する | 横揺れを直接作れるが、半径方向だけという変位契約が変わる |
| 参照 U/V を保存する | 房への配置を固定できるが、今回はユーザーが現行の幾何座標の制約を受け入れたため導入しない |
| V と U の位相を一つにまとめる | 縦方向の伝播と周方向の回転が結合するため採用しない |
| 加算ノイズを位相差へ置き換える | 既存のノイズ表現が失われるため、位相差は別の強度で追加する |
| send の方向を正規化する | 保存済みのベクトル強度が変わるため、独立した倍率を追加する |
| 方向係数、独立振幅、位相差、send 倍率を追加する | 現行の時間依存と変位方向の契約を保ち、必要な表現を直接操作できるため採用する |

## 検収条件

既存テストに加え、以下を実際のノード出力で確認する。
式をテスト内に複製するだけの検証は避け、対称性、独立性、ゼロ寄与、同一入力の再現性を使う。

- 追加属性のノード既定値で従来の出力を維持し、新規ホスト既定値で wave が無変位になる。
- `phaseSpread=0` の方向付き縦波は対向点で半径変位の符号が反転し、直交方向ではゼロになる。
- 方向ベクトルを正の定数倍しても揺れは変わらず、ゼロ方向とベル軸への平行方向では有限のゼロ寄与になる。
- World と Bell Local の意味、ベルの回転、全体スケールを確認する。
- V と U の強度をそれぞれゼロにでき、片方の編集がもう片方の寄与を変えない。
- `waveCountU=0` では U の強度と位相が出力に影響しない。
- 加算ノイズがゼロでも位相差が働き、同じ theta の縦列へ同じ入力位相差を与える。
- 位相差を加えても U の継ぎ目が連続し、複雑度ゼロで整数 cycles のループが成立する。
- `sendAmount=0` では方向と位置の値にかかわらず send の寄与がゼロになる。
- 全体強度、Envelope、ramp、点ウェイトのゼロ寄与と、部分コンポーネントの処理を維持する。
- 全追加入力の同一フレーム編集で出力が更新される。
- DG、Serial、Parallel、順方向と逆方向、サブフレーム、フレームジャンプ、対象入力を揃えたリタイムで一致する。
- ホストの名前、範囲、既定値、接続、旧プラグイン検出、wave 無効時の構築を確認する。
- 試験用の形状で方向付き sway、U のひだ、位相差、send を比較し、画像またはアニメーションを目視する。

Cached Playback と完成リグの操作感を検証できなかった場合は、その範囲を検収記録に残す。
検証前に実行成功と記載しない。

## 再検討の条件

房ごとの配置が形状変更で動くことが制作の障害になった場合は、参照座標の契約を別 ADR で設計する。
方向付きの半径変位で必要なシルエットを作れない場合は、接線方向または高さ方向の変位基底を検討する。
ノイズ操作の共有やホスト属性数が操作を妨げる場合は、実際のショットで使う操作を確認して構成を見直す。
複数の send、厳密な周期ノイズ、長さの保存は、それぞれ独立した要求として扱う。
